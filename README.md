# Pothole Reporting & Alert System

A modern, full-stack smart city solution for reporting and tracking potholes.

## Structure
- **web**: Next.js + Tailwind CSS (Admin Dashboard & Public View)
- **mobile**: React Native + Expo (Driver App & Alerts)
- **functions**: Firebase Cloud Functions (Backend Logic)

## Getting Started

### Web
```bash
cd web
npm install
npm run dev
```

### Mobile
```bash
cd mobile
npm install
npx expo start
```

### Backend
Firebase Functions are located in `functions/`.
